# raylrode.com

Static landing page for Raylrode. Plain HTML with self-hosted fonts and no build step.

Deploy as its own Vercel project from this repo:
- Root Directory: `raylrode-site`
- Framework Preset: Other (no build command)
- Domains: `raylrode.com`, `www.raylrode.com`

Before launch, fill in the highlighted `[...]` placeholders in the About section and check the contact email.
